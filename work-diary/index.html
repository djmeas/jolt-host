Questions & answers

Questions raised during implementation, and their resolution. Pending questions block the phase that raised them.

QuestionAnswerStatus
Who pays for LLM usage — operator key or per-user keys? Operator supplies one server-side key (JOLT_AI_API_KEY, OpenCode gateway, OpenAI-compatible endpoint). No BYOK in MVP; fails closed without a key. answered
Full agent runtime or codegen-only? Codegen-only MVP: one chat turn = one LLM call = one validated JSON file manifest. No shell, no containers; agent runtime deferred to phase 2+. answered
Where does the builder live in the UI? Build tab in the landing-page upload box (Upload | Build tab strip); dashboard keeps a secondary deep link. No new route. answered
Can the builder edit an existing upload? Yes — phase 6: attach an owned site, seed workspace from the live generation, publish via replacement (same URL; expiration, password, Data API state untouched). Binaries carried through as non-editable. answered
What error code names the chat rate limit (plan left it unnamed)? rate_limited — matches the data API's naming style; 429 includes retry_after and Retry-After header. answered
Which 409 code when a turn's CAS fails at finalize (e.g. account deleted mid-call)? workspace_conflict — distinct from workspace_busy (another turn in flight); plan permitted either. answered
Oversized provider manifest — 502 or 413? 502 invalid_model_output. 413 stays reserved for client request bodies; a bad model response is a provider failure, not a client error. answered
Empty workspace at preview — 400 or 409? 409 empty_workspace, per binding plan §7:320 (the task's acceptance bullet misquoted it; subagent correctly followed the plan). answered
Extract the replace-content helper now too? Deferred to phase 6 — that's where its only new caller (attached publish mode) lands. Only createUploadFromContent extracted in phase 4. answered
Who owns adding aiBuilderAvailable to /api/config? Phase 5 — phase 1-2 scoped to server/utils only, so the flag never landed; UI subagent raised the gap live, parent approved, added there. answered
Where does the replacement rate limit live after the helper extraction? In the adapters, once, before the body is read — keeps the existing content-put ordering contract green; the helper carries all other replacement rules. answered
Can attached publish drop a site's binaries? No — buildWorkspaceZip includes opaque assets (hash-identical through publish); new-mode previews unaffected since those workspaces hold no opaque files. answered
Which code for an unusable attached source layout (plan names none)? 400 invalid_path — mapped from the internal manifest code at the attach boundary. answered
Why did the whole dev server hang mid-implementation? Not a product bug: the dev watcher watches test/tmp-storage, and the integration run created hundreds of files → hundreds of Nitro reload events wedged the watcher. Restarting the server fixed it; run integration tests with the dev server stopped, or accept the churn. answered
Does an AI publish ever leak the provider key or raw model output? No — key resolves server-side only and never enters results/transcripts; transcript rows store sanitized content; error finalizations store provider usage where available, never raw responses (asserted across invalid/timeout/overflow paths). answered
AES key chain on the provider key at rest — ADMIN or VIEW secret first? JOLT_ADMIN_SECRET ?? JOLT_VIEW_SECRET ?? dev default — mirroring admin-auth.ts exactly; the plan text had it inverted and the implementer flagged it before implementing. answered
Default state of Build Mode for existing/new users? Off. The admin's per-row toggle is the deliberate grant; tests and the live check prove 403 → toggle → 200 end to end. answered
Chat rejected with invalid_model_output on a healthy provider — bug? No: the smoke mock always "adds" index.html which already existed after restore — add-on-existing is a per-contract manifest violation. POST /api/ai/reset clears the draft; next turn succeeded (revision 7 → 8). answered
